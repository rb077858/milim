# מחזור המלכים במילים

דף סטטיסטיקות לקבוצת הוואטסאפ: תקציב של 500 מילים לכל אחד בכל חודש לועזי, פרסים, כרטיס אישי, ראש בראש ומחשבון מילים.

הדף עצמו: `index.html` (נבנה אוטומטית, לא לערוך ידנית).

## עדכון
1. מייצאים את הצ'אט מוואטסאפ (בלי מדיה).
2. `python3 build/build.py <export.zip>`
3. מעלים את `index.html` המעודכן.

שם למשתתף חדש: `python3 build/build.py --add "+972 50-000-0000" "שם"`

## כללי ספירה
- מילה היא רצף של אותיות או מספרים. מקף, קו תחתון, נקודה ולוכסן מפרידים בין מילים.
- כל תמונה, סרטון, סטיקר, הודעה קולית או קובץ = 20 מילים.
- סקרים נספרים. קישורים, הודעות שנמחקו, אימוג'ים והודעות מערכת לא נספרים.

## פרטיות
המאגר לא מכיל את הצ'אט, מספרי טלפון או שמות מלאים. השמות שמורים ב-`build/names.json` לפי גיבוב (hash) של השולח, והדף כולל רק נתונים מספריים, בלי תוכן ההודעות.
